# 🐍 Python Mini Projects

A collection of small Python projects built while learning core concepts — GUI development, APIs, game logic, and everyday utilities.

## 📂 Projects

| Project | Description |
|---|---|
| 🏦 Banking Program | Simulates basic banking operations (deposit, withdraw, balance check) |
| 🧮 Calculator | Basic arithmetic calculator |
| 🕐 Digital Clock | Live-updating digital clock built with PyQt5 |
| 🔢 Number Guessing Game | Random number guessing game with user input validation |
| 🔐 Password Generator | Generates secure random passwords |
| 📱 QR Code Generator | Generates QR codes from user input |
| ❓ Quiz | Interactive quiz app with score tracking |
| ✂️ Rock Paper Scissors | Classic game vs. computer with random logic |
| 🛒 Shopping Cart | Simulates adding/removing items and calculating totals |
| 🎰 Slot Machine | Simple slot machine simulation game |
| ⏱️ Stopwatch | Real-time stopwatch built with PyQt5's QTimer |
| ⏲️ Timer | Countdown timer app |
| ✅ To Do List | Task manager to add, complete, and remove tasks |
| 🌦️ Weather App | Fetches live weather data using the OpenWeatherMap API |

## 🛠️ Built With
- Python
- PyQt5 (for GUI-based projects)

## 📌 Note
These are learning projects built while strengthening Python fundamentals — OOP, GUI development, API integration, and basic algorithmic logic.
